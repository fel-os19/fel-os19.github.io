Sobre el proyecto

Proyecto académico que explora el cálculo de rutas mediante estructuras de grafos y el algoritmo de Dijkstra. No se afirman métricas de rendimiento no documentadas.

Problema

Encontrar la ruta de costo mínimo entre dos vértices de un grafo.

02.

03.

Demostración

El laboratorio web muestra el algoritmo paso a paso con un grafo de ejemplo.
