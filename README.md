# FEL-OS19 | Portfolio v2

Sitio estático bilingüe, sin dependencias ni compilación.

## Publicación
Extrae el ZIP. En el repositorio fel-os19.github.io, rama main, usa Add file > Upload files y selecciona todos los archivos extraídos, no el ZIP. Confirma que index.html y README.md se reemplazan. Commit directamente a main. Pages debe seguir en main / (root). Revisa Actions y visita el sitio. Si Safari no permite seleccionar varios archivos, utiliza un computador. El archivo oculto .nojekyll es opcional en esta versión; puedes crearlo vacío por separado.

## Edición
- index.html / en.html: inicio.
- projects.html / projects-en.html y páginas de casos: portafolio.
- profile.html / profile-en.html: perfil y certificados.
- cv.html / cv-en.html: currículum imprimible.
- styles.css: diseño; site.js: tema y botón imprimir.
- Cambia las URL canónicas y sitemap si conectas un dominio.

## Antes de compartir con reclutadores
Revisar títulos de certificados frente a documentos originales, agregar enlaces de verificación, actualizar fechas académicas cuando cambien y agregar un correo profesional público o LinkedIn verificado. No publicar información privada ni código académico sin permiso. Las ilustraciones son conceptuales. El CV no es un PDF preexistente: puede imprimirse o guardarse como PDF.

## Desarrollo local
Ejecuta python -m http.server 8000 desde la carpeta y abre http://localhost:8000. No hay backend ni secretos.
